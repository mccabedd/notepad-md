## Notepad MD v1.0.1

If you have v1.0.0, open **About → About Notepad MD → Check for Updates** to install this version. It reopens with all your tabs.

### New
- **Drag tabs to rearrange them.** Pinned tabs stay together on the left, and the order is remembered.
- **Insert Image** toolbar button. Pick a picture and it's added as `![name](path)`, relative to the document if the document has been saved. Local images now show in the preview.
- **One window.** Opening a file while Notepad MD is running (double-click, *Open with*, command line) adds it as a tab in the open window instead of starting a second copy.

### Fixed
- An empty *Untitled* tab no longer disappears when you close and reopen the app.
- New documents take the lowest free number (*Untitled 2* is reused after you close it), like Notepad++.
