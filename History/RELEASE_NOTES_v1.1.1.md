## NotePad-MD v1.1.1

If you have an earlier version, open **About → About NotePad-MD → Check for Updates** to install this one. It reopens with all your tabs.

### Changed
- **One name everywhere: NotePad-MD.** The app's name is now spelled the same way in every place it appears:
  - the window title and the About box;
  - menus, messages and Settings;
  - Explorer's **Open with** list and the **Edit in NotePad-MD** right-click item;
  - the program's own file details, and the documentation.
- If you had already registered file types or the Explorer menu item, click **Register** (or switch the menu item off and on) in **Settings** once to show the new name there.
- Your tabs, settings and file associations carry over unchanged.

### Also in recent versions
If you're updating from v1.0.7 or earlier, this version also includes everything from v1.0.8 to v1.1.0:
- a new tab is ready to type into straight away;
- the **+** tab;
- separate default font sizes for the editor and the preview;
- faster typing in larger files;
- find highlights in big logs;
- safer saving and a safe preview;
- verified updates;
- the Windows 11 look and the Windows accent colour.

The notes for each version are in the [History folder](https://github.com/mccabedd/notepad-md/tree/main/History).
