## NotePad-MD v1.0.2

If you have v1.0.0 or v1.0.1, open **About → About NotePad-MD → Check for Updates** to install this version. It reopens with all your tabs.

### New
- **Edit in NotePad-MD** in Explorer's right-click menu, with the app's icon. Turn it on in **Settings → Files**. On Windows 11 it's under *Show more options* (or Shift+right-click).
- **More languages:** Java, CSS, C, C# and C++ (`.java`, `.css`, `.c` / `.h`, `.cs`, `.cpp` / `.cc` / `.cxx` / `.hpp`), with syntax colouring. `.bat` / `.cmd`, `.ps1` and `.js` continue to open as MS-DOS Batch, PowerShell and JavaScript.
