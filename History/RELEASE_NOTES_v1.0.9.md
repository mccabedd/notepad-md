## NotePad-MD v1.0.9

If you have an earlier version, open **About → About NotePad-MD → Check for Updates** to install this one. It reopens with all your tabs.

### New
- **A [+] tab for new tabs.** A little **+** tab always sits after the last tab. When there are too many tabs to fit, it stays in view beside the scroll arrows. `Ctrl+N` and double-clicking the empty part of the tab bar still work too.
- **Separate default font sizes for the editor and the preview.** Set them in **Settings → Editor → Font size** and **Settings → Preview → Font size**. They're the sizes at 100%; zooming a tab (`Ctrl`+mouse wheel, `Ctrl++` / `Ctrl+-`) scales both, and `Ctrl+0` goes back to them.
  - If you had changed the old "new tab font size", both new settings start from that value, so nothing changes when you update.
