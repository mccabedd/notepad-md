## Notepad MD v1.1.0

If you have an earlier version, open **About → About Notepad MD → Check for Updates** to install this one. It reopens with all your tabs.

### Fixed
- **A new tab is ready to type into straight away.** Before, typing after opening a new tab could go nowhere, or into the tab you were in before.
  - The caret is now placed in the new tab, in the editor or, in Preview Only, in the preview.
  - This works however you open the tab: the **+** tab, `Ctrl+N`, **File → New**, or double-clicking the empty part of the tab bar.

### Also in recent versions
If you're updating from v1.0.7 or earlier, this version also includes everything from v1.0.8 and v1.0.9:
- the **+** tab;
- separate default font sizes for the editor and the preview;
- faster typing in larger files;
- find highlights in big logs;
- safer saving and a safe preview;
- verified updates;
- the Windows 11 look and the Windows accent colour.

The notes for each version are in the [History folder](https://github.com/mccabedd/notepad-md/tree/main/History).
